Добавление водяного знака или даты печатиЗачем: Для упрощения учета на складе.Как работает: Бот может автоматически добавлять мелким шрифтом внизу каждого стикера дату и время обработки (например: Собрано: 27.09.2026 14:30) или номер партии.2. Сортировка накладных внутри файлаПо алфавиту / названиям: Сортировать накладные так, чтобы товары из одинаковых категорий или с похожими названиями шли друг за другом.По количеству товаров: Сначала накладные с 1 товаром, затем с 2 и более — это ускоряет сборку заказов на складе.3. Формирование «Листа сборки» (Pick List)Зачем: Чтобы кладовщику не нужно было бегать по складу с каждой накладной отдельно.Как работает: Вместе с готовым PDF для печати бот отправляет короткий текстовый отчет или мини-документ:📦 Лист сборки заказов:• Чехол для iPhone 13 (Черный) — 5 шт.• Беспроводные наушники X1 — 3 шт.• Защитное стекло — 8 шт.4. Автоматическое обрезание пустых полей (Crop)Зачем: Из Kaspi накладные иногда выгружаются с широкими белыми полями по бокам, из-за чего сам штрихкод при печати получается мелким.Как работает: Код автоматически подрезает пустые поля вокруг текста и делает штрихкод максимально крупным на весь формат этикетки (75×120 мм).5. Режим «Несколько копий»Зачем: Некоторые продавцы клеят один стикер на упаковку, а второй вкладывают внутрь коробки.Как работает: Добавить кнопку в настройки: Дублировать этикетки: [Вкл / Выкл].6. Реферальная система (Приведи друга)Зачем: Для бесплатного привлечения новых селлеров без трат на рекламу.Как работает: Пользователь получает персональную ссылку (t.me/KaspiPrintBot?start=ref12345). За каждого приведенного коллегу-селлера ему дается +10 бесплатных обработок или 3 дня подписки BASIC.
